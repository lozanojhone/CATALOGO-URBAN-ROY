IMPORTANTE:
1. Debe publicarse mediante HTTPS. GitHub Pages ya usa HTTPS.
2. No abras index.html como archivo local.
3. Borra la instalación antigua/acceso directo antes de probar el nuevo icono y nombre.
4. En Chrome Android: abre el sitio, espera unos segundos y pulsa Instalar.
5. En iPhone: Safari > Compartir > Agregar a pantalla de inicio.
6. Si se conserva el icono anterior, borra los datos del sitio o espera la actualización del manifest y vuelve a instalar.
